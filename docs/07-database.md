# 07 — Database (Neon + Drizzle)

Postgres holds **durable, low-frequency** data only. Live game state is never in Postgres.

Driver: `drizzle-orm/neon-http` with `@neondatabase/serverless` (HTTP, no pooling issues on Vercel).
Free plan: 0.5 GB — keep rows lean, prune logs.

## Tables

Better Auth core tables (`user`, `session`, `account`, `verification`) are generated by Better Auth's CLI; `user` gets the extra fields from `06-auth.md`.

```ts
// packages/db/src/schema/game.ts (Drizzle, abbreviated)
export const gameSlug = pgEnum("game_slug", ["whot", "ludo", "snakes", "tictactoe", "rps"]);

export const match = pgTable("match", {
  id: text("id").primaryKey(),                        // ULID
  roomId: text("room_id").notNull(),
  game: gameSlug("game").notNull(),
  kind: text("kind", { enum: ["private", "quick"] }).notNull(),
  ranked: boolean("ranked").notNull(),
  playerCount: smallint("player_count").notNull(),
  rules: jsonb("rules").notNull(),
  startedAt: timestamp("started_at", { withTimezone: true }).notNull(),
  endedAt: timestamp("ended_at", { withTimezone: true }).notNull(),
}, (t) => [uniqueIndex("match_room_start_uq").on(t.roomId, t.startedAt), index("match_ended_idx").on(t.endedAt)]);

export const matchPlayer = pgTable("match_player", {
  matchId: text("match_id").notNull().references(() => match.id, { onDelete: "cascade" }),
  seat: smallint("seat").notNull(),
  userId: text("user_id").references(() => user.id, { onDelete: "set null" }), // null = bot or deleted
  isBot: boolean("is_bot").notNull(),
  botLevel: text("bot_level"),
  displayName: text("display_name").notNull(),
  place: smallint("place").notNull(),                 // 1 = winner; ties share a place
  leftEarly: boolean("left_early").notNull().default(false),
  ratingBefore: real("rating_before"),                // ordinal, ranked only
  ratingAfter: real("rating_after"),
}, (t) => [primaryKey({ columns: [t.matchId, t.seat] }), index("mp_user_idx").on(t.userId, t.matchId)]);

export const rating = pgTable("rating", {
  userId: text("user_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  game: gameSlug("game").notNull(),
  mu: real("mu").notNull().default(25),
  sigma: real("sigma").notNull().default(25 / 3),
  ordinal: real("ordinal").notNull().default(0),      // mu - 3*sigma, used for display/sort
  played: integer("played").notNull().default(0),
  won: integer("won").notNull().default(0),
  updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
}, (t) => [primaryKey({ columns: [t.userId, t.game] }), index("rating_board_idx").on(t.game, t.ordinal)]);

export const userStats = pgTable("user_stats", {            // all games incl. unranked
  userId: text("user_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  game: gameSlug("game").notNull(),
  played: integer("played").notNull().default(0),
  won: integer("won").notNull().default(0),
  currentStreak: integer("current_streak").notNull().default(0),
  bestStreak: integer("best_streak").notNull().default(0),
}, (t) => [primaryKey({ columns: [t.userId, t.game] })]);

export const friendship = pgTable("friendship", {           // stored once per pair, userA < userB
  userA: text("user_a").notNull().references(() => user.id, { onDelete: "cascade" }),
  userB: text("user_b").notNull().references(() => user.id, { onDelete: "cascade" }),
  createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
}, (t) => [primaryKey({ columns: [t.userA, t.userB] }), index("friend_b_idx").on(t.userB)]);

export const friendRequest = pgTable("friend_request", {
  fromId: text("from_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  toId: text("to_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
}, (t) => [primaryKey({ columns: [t.fromId, t.toId] }), index("fr_to_idx").on(t.toId)]);

export const block = pgTable("block", {
  blockerId: text("blocker_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  blockedId: text("blocked_id").notNull().references(() => user.id, { onDelete: "cascade" }),
}, (t) => [primaryKey({ columns: [t.blockerId, t.blockedId] })]);

export const report = pgTable("report", {
  id: text("id").primaryKey(),
  reporterId: text("reporter_id").references(() => user.id, { onDelete: "set null" }),
  targetId: text("target_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  roomId: text("room_id").notNull(),
  reason: text("reason", { enum: ["abuse", "hate", "sexual", "spam", "cheating", "other"] }).notNull(),
  message: text("message"),                            // verified signed chat text
  status: text("status", { enum: ["open", "actioned", "dismissed"] }).notNull().default("open"),
  createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
}, (t) => [index("report_status_idx").on(t.status, t.createdAt), index("report_target_idx").on(t.targetId)]);

export const moderationAction = pgTable("moderation_action", {
  id: text("id").primaryKey(),
  adminId: text("admin_id").notNull().references(() => user.id),
  targetId: text("target_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  action: text("action", { enum: ["warn", "chat_mute", "ban", "unban"] }).notNull(),
  until: timestamp("until", { withTimezone: true }),
  note: text("note"),
  createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
});

export const emailLog = pgTable("email_log", {
  id: bigserial("id", { mode: "number" }).primaryKey(),
  kind: text("kind").notNull(),
  toHash: text("to_hash").notNull(),                  // sha256(lowercased email)
  status: text("status", { enum: ["sent", "failed", "skipped_quota"] }).notNull(),
  createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
}, (t) => [index("email_log_created_idx").on(t.createdAt)]);
```

Add to `user`: `chatMutedUntil timestamp`, `soundOn boolean default true`, `reducedMotion boolean default false`.

## Size estimate (0.5 GB)

| Table | Row ≈ | 10k users, 100k matches |
|---|---|---|
| match | 300 B | 30 MB |
| match_player (avg 3.5) | 120 B | 42 MB |
| others | — | < 20 MB |

Well within 0.5 GB for a long time. Prune `email_log` > 30 days on each sign-up (cheap `DELETE … WHERE created_at < …` with limit).

## Key queries

- **Profile**: `user_stats` by user; last 20 `match_player` join `match` by `(user_id, match_id desc)`.
- **All-time leaderboard**: `rating where game = ? and played >= 10 order by ordinal desc limit 100`. Cached with `"use cache"` + `cacheLife("minutes")`, tag `leaderboard:<game>`, revalidated on match ingest (`revalidateTag`).
- **Weekly leaderboard**: sum of `rating_after - rating_before` for ranked matches with `ended_at >= start of week (Monday 00:00 Africa/Lagos)`, grouped by user, min 5 games. Same caching.
- **Friends**: `friendship where user_a = $me or user_b = $me` (both indexed).

## Migrations

`drizzle-kit generate` → commit SQL → `drizzle-kit migrate` in CI before deploy. Never `push` against prod.
